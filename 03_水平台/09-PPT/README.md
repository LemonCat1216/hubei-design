# 水环境形势分析PPT — 编写规范

## 1. 时态命名规范

| 术语 | 含义 | 写法示例 |
|------|------|----------|
| 累计月 | 1-5月累计口径（看存量） | `省控断面累计月市州达标` |
| 当前月 | 5月单月口径（看变量） | `2026年5月（当前月）` |
| 同比 | 与去年同期对比 | `同比 <span>↓0.5%</span>` |
| 环比 | 与上月对比 | `环比 <span>↑0.3%</span>` |

- `当前月` 在月份后出现时加括号：`5月（当前月）`
- `累计月` 在月份后出现时也必须完整写出：`1-5月（累计月）`，不可简写为`（累计）`
- `累计月` 本身已是完整词，不加括号

## 2. 同环比显示规则

- **有环比的地方必须配同比**，反之亦然
- 右上角徽章格式（参照 P05）：

```html
<div style="display:flex;gap:8px;font-size:9px;align-items:center;">
  <span style="color:#64748B;">同比 <span style="color:#DC2626;font-weight:700;">↓0.5%</span></span>
  <span style="color:#64748B;">环比 <span style="color:#059669;font-weight:700;">↑0.3%</span></span>
</div>
```

- 颜色规则：改善/上升 = `#059669`（绿），恶化/下降 = `#DC2626`（红），持平 = `#64748B`（灰）

## 3. 断面层级

| 层级 | 断面数 | 适用页面 |
|------|--------|----------|
| 国控断面 | 167 个 | P03, P04, P11~P20 |
| 省控断面 | 334 个 | P05, P06 |

- 文案中需附带断面总数，如 `全省334个省控断面`

## 4. 文件命名

| 类型 | 格式 | 示例 |
|------|------|------|
| 主页面 | `Page{编号}.html` | `Page5.html` |
| 补充页 | `Page{编号}a.html` | `Page04A.html` |
| 样式 | `ppt-style.css` | 全局样式 |
| 目录 | `index.html` | 页面导航 |

- 编号格式：P + 两位数字，补充页加字母后缀（大写）

## 5. 核心表述

| 正面表达 | 负面表达 |
|----------|----------|
| 全面达标 | 超标预警 |
| 环比改善 | 环比恶化 |
| 显著改善 / 基本持平 | 明显恶化 |
| 达标湖泊 | 未达标湖泊 |

- `KPI卡片` 标签名称统一：
  - 卡片标题用 KPI 名称（省控Ⅰ-Ⅲ类比例）
  - 右上角放同环比数据（同比↓/环比↑）
  - 下半部分放进度条 + 数据口径说明

## 6. 页面布局规范

- 左侧 `left-column`：KPI卡片 + 预警卡片
- 右侧 `right-column`：表格/热力图/图表
- 左右底部需对齐，通过调整左侧卡片间距实现
- `core-bar`：单行概括该页核心结论，不超过两行

## 7. core-bar 规范

每个页面的核心结论条（core-bar）必须包含以下要素：

| 要素 | 要求 | 示例 |
|------|------|------|
| 年份 | 统一用 `2026年` | `2026年1-5月（累计月）` |
| 时态 | `（累计月）`或`（当前月）` | `2026年5月（当前月）` |
| 断面口径 | 国控/省控 + 总数 | `全省334个省控断面` |
| 核心指标 | Ⅰ-Ⅲ类比例/劣Ⅴ类数/CWQI等 | `Ⅰ-Ⅲ类比例86.8%` |
| 同环比 | 同比/环比数据 | `（同比↓3个，环比↑1个）` |
| 动作指向 | 督办/整改/重点关注 | `建议对潜江、荆州启动挂牌督办` |

句式示例：
- 累计月：`▎ 2026年1-5月（累计月），……`
- 当前月：`▎ 2026年5月（当前月），……`

## 8. 数据单位

| 指标 | 单位 |
|------|------|
| Ⅰ-Ⅲ类比例 | %（保留1位小数）|
| CWQI | 数值（保留2位小数）|
| 断面数 | 个 |
| 同比/环比变化 | % 或 个 |
## 9. 水质类别表述规范

| 术语 | 规范写法 | 错误示例 |
|------|----------|----------|
| 优良水质类别 | 优良（Ⅰ-Ⅲ类） | 优良(Ⅰ-Ⅲ)（半角括号、缺"类"）|
| 优良占比 | 优良（Ⅰ-Ⅲ类）比例 或 优良（Ⅰ-Ⅲ类）占比 | 优良(Ⅰ-Ⅲ)占比 |
| 其他水质类别 | 劣Ⅴ类、Ⅳ类、Ⅲ类 等 | 无 |

规则：
- 水质类别名称统一使用**全角括号** （），不得使用半角 ()
- 类别数字后必须带 类 字，如 Ⅰ-Ⅲ类、劣Ⅴ类
- 示例：优良（Ⅰ-Ⅲ类）比例89.9% ✓ | 优良(Ⅰ-Ⅲ)占比89.9% ✗
## 10. 核心结论条（core-bar）统一规范

所有页面的核心结论条必须遵循以下格式：

### 基本格式
`
▎ 2026年5月（当前月），全省XXX个国控/省控断面，[描述内容]。
▎ 2026年1-5月（累计月），全省XXX个国控/省控断面，[描述内容]。
`

### 规范要点

| 要素 | 要求 | 正确示例 | 错误示例 |
|------|------|----------|----------|
| 前缀 | 统一使用 ▎ | ▎ 2026年... | 无前缀或其他符号 |
| 时间 | 全角括号（当前月）/（累计月） | 2026年5月（当前月） | 2026年5月(当前月) 或 本月 |
| 断面口径 | 明确国控或省控 | 全省167个国控断面 | 全省167个断面 |
| 断句 | 口径后跟逗号，不用冒号 | 断面，Ⅰ-Ⅲ类比例 | 断面：Ⅰ-Ⅲ类比例 |
| 数据 | 数值精确，同环比齐全 | 比例86.8%，环比+0.3% | 比例约87% |

### 各类场景模板

**场景一：水质排位（P03/P04/P04A）**
▎ 2026年1-5月（累计月），全省167个国控断面Ⅰ-Ⅲ类水质比例为xx%，排名第x位。

**场景二：市州达标（P05/P06）**
▎ 2026年5月（当前月），全省334个省控断面Ⅰ-Ⅲ类比例xx%，[同环比]。共x个地市x个断面超标。

**场景三：流域分析（P11~P15）**
▎ 2026年5月（当前月），[流域名称]x个国控断面Ⅰ-Ⅲ类比例xx%，[具体分析]。

**场景四：湖泊监测（P16~P19）**
▎ 2026年5月（当前月），[湖泊名称]共x个监测点位，[水质结论]。

**场景五：排污口/资金（P21~P29）**
▎ 2026年5月（当前月），全省入河排污口x个，[整治进展]。

**场景六：问题督办（P30~P32）**
▎ 2026年5月（当前月），全省[问题类型]共x件，[处置进展]。
### 适用范围说明

**必须使用（当前月）/（累计月）的页面：**
断面类页面：P03~P06（国控/省控排位与达标）、P11~P20（流域与湖库分析）、P20B~P20D（风险断面攻坚）。

**不需要使用（当前月）/（累计月）的页面（子系统类）：**
P21~P29（排污口排查整治、黑臭水体、饮用水源、资金项目、其他业务）——这些页面属于功能子系统，数据口径为累计存量或阶段性进展，非断面月度监测数据，因此只需标注"2026年5月"即可，不加时态后缀。
P2a（月度核心研判）——属于综述性页面，不加时态后缀。
P30~P32（问题督办与总结）——按需决定，不加也行。
