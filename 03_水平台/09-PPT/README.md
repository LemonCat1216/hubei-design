# 湖北省水生态环境形势分析汇报 —— PPT 页面项目

## 设计系统（ppt-style.css v3.0）

### 主容器

- 宽高比 **16:9**，最大宽度 `860px`
- 页面缩放 `zoom: 175%`（适配高清屏）
- 背景色 `#F1F4F9`

### 页眉（ppt-header）

- 深蓝渐变 `#0F2942 → #1A3A5C → #1E4470`
- 白色文字，底部绿色边框 `border-bottom: 3px solid #047857`
  - 右侧页码徽章（深绿底色 `#047857`）

### 核心结论条（core-bar）

- 浅绿渐变背景 `#ECFDF5 → #F0FDF4`
- 绿色文字 `#065F46`
- 前缀统一使用 `▎`
- 格式：`▎ 年份 + 时态（当前月/累计月）+ 断面口径 + 核心指标 + 同环比 + 动作指向`

### 主体区域（.bd）

- 浅灰背景 `#F5F7FA`
- 左右分栏：`left-column`（KPI 卡片 + 预警卡片） / `right-column`（图表 / 表格）

### KPI 卡片

- 白色背景，圆角 `3px`，阴影 `0 2px 12px rgba(15,23,42,.06)`
- 必须保留 `1px` 可见边框和 `2px` 顶部语义色边线，不允许做成无边框白卡
- 标题 `11px` 深灰，数值 `26px` 粗体深黑
- 语义配色：绿色 `#047857`（好）、琥珀色 `#B45309`（警告）、红色 `#991B1B`（预警）
- 默认/中性 KPI 使用白底 + `#E2E8F0` 边框 + `#1A3A5C` 顶部边线
- 使用状态类表达语义：`.status-good`、`.status-warn`、`.status-alert`，不要在页面内写临时边框色

| KPI 状态类 | 适用场景 | 背景色 | 边框色 | 顶部边线/强调色 |
|------------|----------|--------|--------|----------------|
| 默认 `.kpi-card` / `.pos1` | 排名、总量、维度标识、中性指标 | `#FFFFFF` / `#F8FAFC` | `#E2E8F0` | `#1A3A5C` |
| `.status-good` | 达标、改善、排名上升、进展较好 | `#F5FBF7` | `#DCFCE7` | `#047857` |
| `.status-warn` | 关注、轻度恶化、指数偏高、进度一般 | `#FFFAF4` | `#FEF3C7` | `#B45309` |
| `.status-alert` | 超标、严重预警、恶化、风险突出 | `#FCF6F6` | `#FEE2E2` | `#991B1B` |

**KPI 色块一致性要求：** KPI 卡片需与预警卡片、状态节点等语义色块保持同一套边框语言：浅色底、同色系边框、顶部细边线。不要使用渐变边框、无边框白块或单页自定义色值覆盖该标准。

### 语义色块配色标准

所有语义色块（预警卡片/KPI色块/状态节点）统一遵循以下标准：

| 语义级别 | 适用场景 | 背景色 | 边框色 | 强调色 |
|----------|----------|--------|--------|--------|
| 🔴 红色（严重/预警） | 超标断面、恶化趋势、alert-card | `#FEF2F2` | `#FEE2E2` | `#991B1B` |
| 🟢 绿色（良好/改善） | 达标断面、改善趋势、green-card | `#F0FDF4` | `#DCFCE7` | `#047857` |
| 🟡 黄色（提示/关注） | 一般预警、warning-card 默认 | `#FFFBEB` | `#FDE68A` | `#B45309` |
| 🔵 蓝色（信息提示） | 信息说明、blue-card | `#EFF6FF` | `#BFDBFE` | `#1E40AF` |

**红色边框配色说明（红榜参照）：** 源自 Page04A `CWQI 水质排名后三 (红榜)` 设计语义，红色块使用 `#FEF2F2` 浅红背景 + `#FEE2E2` 边框 + `#991B1B` 强调色，避免使用 `#FFF1F2`（偏粉）和 `#FCA5A5`（偏亮）等不一致色值。

### 表格

- 表头深蓝渐变 `#1A365D → #2B4C7E`
- 行斑马纹 `#F8FAFC`
- 文字 `10px`，hover 高亮

### 预警卡片

- 黄色背景 `#FFFBEB` + 黄色边框（常规预警）
- 红色背景 `#FEF2F2` + 红色边框（严重预警 alert-card）
- 蓝色背景 `#EFF6FF`（信息提示）
- 绿色背景 `#F0FDF4`（向好提示）
- 标题 `.card-loc`，内容 `.card-det`

### 图表区（chart-wrapper）

- ECharts 5 渲染堆叠柱状图、趋势折线图、CWQI 横向条形图
- 白色背景，圆角 `3px`

### 页脚

- 浅灰背景 `#F8FAFC`，灰色文字 `#94A3B8`
- 上边框 `#E2E8F0`

## 数据规范

### 时态命名

| 术语 | 含义 | 写法 |
|------|------|------|
| 累计月 | 1-5月累计口径 | `1-5月（累计月）` |
| 当前月 | 5月单月口径 | `5月（当前月）` |
| 同比 | 与去年同期对比 | `同比 ↓0.5%` |
| 环比 | 与上月对比 | `环比 ↑0.3%` |

### 断面层级

| 层级 | 断面数 | 适用页面 |
|------|--------|----------|
| 国控断面 | 167 个 | P03, P04, P11~P20 |
| 省控断面 | 334 个 | P05, P06 |

### 同环比颜色规则

- 改善/上升 → `#059669`（绿）
- 恶化/下降 → `#DC2626`（红）
- 持平 → `#64748B`（灰）

### 水质类别表述

- 使用全角括号 （），如 `优良（Ⅰ-Ⅲ类）比例`
- 数字后带"类"字，如 `Ⅰ-Ⅲ类`、`劣Ⅴ类`

### 数据单位

| 指标 | 单位 |
|------|------|
| Ⅰ-Ⅲ类比例 | %（保留1位小数） |
| CWQI | 数值（保留2位小数） |
| 断面数 | 个 |
| 同比/环比变化 | % 或 个 |

### 核心结论条（core-bar）格式

```
▎ 2026年1-5月（累计月），全省167个国控断面Ⅰ-Ⅲ类水质比例为xx%，xx。
▎ 2026年5月（当前月），全省334个省控断面，xx。
```

- 必含：年份、时态、断面口径（国控/省控 + 总数）、核心指标、同环比、动作指向
- 整句用逗号串联，不可使用"标题：正文"的冒号断句模式

### 时态后缀适用范围

- **必须使用**（当前月）/（累计月）：断面类页面 P03~P06、P11~P20、P20B~P20D
- **不需要使用**：子系统类 P21~P29（排污口排查整治、黑臭水体、饮用水源、资金项目）、综述页 P2a、问题督办 P30~P32

## 预览与使用

直接在浏览器打开 `index.html` 即可预览所有 PPT 页面，支持：

- 左侧侧边栏快速跳转
- 键盘 ← → 翻页
- 全屏演示模式（点击"全屏演示"或按 F 键）
- 页面自适应缩放

无需任何后端服务或构建工具，纯静态 HTML。
